# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| < 5.0   | :x:                |

> **v5.0.0:** v5.0.0 is a complete product overhaul with sweeping, authorized breaking changes (see [ADR006](doc/adr/ADR006V01-mandate-for-a-complete-product-overhaul-in-v5-with-authorized-breaking-changes.md)). Now that v5.0.0 has shipped, only the latest major is supported — 4.x (and earlier) receive no further fixes, including the concurrency issues already tracked in [ADR001](doc/adr/ADR001V01-concurrency-model-for-ringbuffermanager-scale-up-and-down.md).

## Reporting a Vulnerability

Please report (suspected) security vulnerabilities to frcerqueira@live.com. If the issue is confirmed, we will release a patch as soon as possible depending on complexity.
